# CampusConnect — Student Event Hub

A responsive, multi-page academic website made with HTML, CSS, and JavaScript. It is static and compatible with GitHub Pages.

## Pages
- `index.html` — landing page and featured events
- `events.html` — event list with working text search, category filter, and demo registration-interest buttons
- `about.html` — project overview and technology list
- `contact.html` — validated demo contact form with on-page confirmation
- `assets/style.css` — responsive design and styling
- `assets/script.js` — mobile navigation and page interactions

## Run locally
Open `index.html` in a browser. No server or database is required.

## Publish using GitHub Pages
1. Create a public repository named `CampusConnect-Student-Event-Hub`.
2. Upload the extracted project files and folders to the repository root.
3. Go to **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the deployment to finish. GitHub will show the live website URL in Settings → Pages.

## Important
The events are sample content. Registration buttons only display a demo confirmation; they do not submit a real registration. The contact form does not send or store messages.
